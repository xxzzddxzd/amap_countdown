# AMap Signal Countdown

适用于高德地图 `com.autonavi.amap` 16.11.1 的 rootless 红绿灯倒计时插件，支持汽车和自行车导航。

## 功能

- 读取高德进程内已有的原生红绿灯状态和倒计时数据。
- 以可拖动悬浮球显示灯色、灯名、剩余秒数和到当前路口的原生沿路线距离，松手后自动贴靠屏幕左侧或右侧。
- 单击悬浮球进入全屏倒计时，双击全屏退出。
- 全屏数字按最多三位数固定字号；两位数和一位数不会继续放大。
- 经过当前路口后，在高德提供下一路口数据时自动切换倒计时。
- 暂无有效数据时显示灰色等待状态。

## 边界

插件不使用 OCR、网络拦截、GPS 或经纬度距离推算，也不进行视图树扫描或全进程内存扫描，不提供抢灯、加速或减速建议。路口距离来自高德导航引擎当前 route offset 与倒计时 signal route offset 的原生差值。

倒计时仅供参考，始终以现场交通信号灯、道路状况和交通规则为准。
